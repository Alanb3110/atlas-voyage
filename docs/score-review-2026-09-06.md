# Revue contradictoire des scores — 6 septembre 2026

## Principe

Cette revue ne recalcule pas toutes les préférences. Elle modifie uniquement les notes directement affectées par le registre homogène `data/longlist-evidence.json`.

La qualité des sources n'ajoute pas de points en elle-même. Une confiance plus élevée réduit seulement l'incertitude méthodologique lorsque la donnée est effectivement mieux contrainte.

Les observations d'animaux sauvages ne sont jamais garanties.
